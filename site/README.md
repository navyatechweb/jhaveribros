# Jhaveri Bros. & Co. Pvt. Ltd. — Official Website

A luxury digital experience celebrating over a century of fine craftsmanship in trophies, awards, salvers, medals, shields, plaques, and corporate gifts from Metro House, Dhobi Talao, Mumbai (Est. 1914).

## Architecture & Structure
```
site/
├── index.html                  # Heritage-led Hero & Bento Master Showcase
├── about-us.html               # 112-Year History, Founder Lineage & Legacy
├── services.html               # Master Craftsmanship & Customization Techniques
├── clientele.html              # Distinguished Institutional & Corporate Patronage
├── enquiry.html                # Bespoke Quotation & Commission Builder
├── contact.html                # Metro House Showroom, Maps & Direct Enquiries
├── products.html               # Comprehensive Product Galleries
├── products/
│   ├── trophies.html           # Custom Trophies (Crystal, Wood, Metal, Acrylic)
│   ├── corporate-gifts.html    # Executive Gifts, Timepieces & Sets
│   ├── cups-medals-shields.html# Sports & Academic Honours
│   ├── plaques.html            # Commemorative & Recognition Plaques
│   ├── salvers.html            # Engraved & Hallmarked Salvers
│   └── silver.html             # Pure Silver Artifacts & Keepsakes
├── privacy-policy.html         # Privacy Policy & Data Protection
├── terms-and-conditions.html   # Terms of Service & Business Operations
├── disclaimer.html             # Legal Disclaimers
├── 404.html                    # Luxury Custom Not Found Experience
└── assets/
    ├── css/style.css           # Luxury Editorial Design System (Burgundy & Warm Gold)
    ├── js/main.js              # Interactive Sliders, Filter Systems, Lightbox & Handoff
    └── img/                    # Archival, Product, Historical & Notable Commission Media
```

## Running & Building
```bash
npm install
npm run dev     # Start local development server
npm run build   # Compile production bundle to dist/
npm run preview # Preview production build
```
